Needs quickshell, python3, jq, curl, libinput-utils (libinput-tools on Debian/Ubuntu), Fira Code.

Clone into `~/.config/quickshell/qedex` and run with `qs -c qedex`.

`cp config.example.json config.json` and set your location (plane + ISS panels use it).

Add yourself to the `input` group for the on-screen keyboard (log out/in after).

Launcher keybind: `qs -c qedex ipc call launcher focus`

Optional: kitty + yazi (folder tiles, change in config), pw-play or paplay for sounds.
